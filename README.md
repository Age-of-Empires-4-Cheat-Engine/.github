## ❓ FAQ

### Do I need to run it as Administrator?

No. This repository is an informational reference and does not contain software that needs to be launched.

### Does this repository include a Cheat Engine table?

No. It does not provide memory-editing tables, trainers, executables, or ready-to-run scripts.

### How do I enable official cheats in Age of Empires IV?

Create a Custom or Skirmish match and enable the Cheats Allowed option in the game settings. Enter the desired cheat code in the in-game chat.

### Can I use cheats in Ranked or Quick Match?

No. Official Age of Empires support states that cheats cannot be used in Ranked or Quick Match modes.

### Do official cheats affect achievements?

Yes. Using cheats stops progression toward achievements, challenges, and masteries for that game session.
